# LPR 借贷计息计算器

一个纯前端的 LPR（贷款市场报价利率）借贷计息计算工具，支持多笔借款与还款的分段利率精确计算。

**[在线体验](https://lpr.k1kyo.com/)**

---

## 功能特性

### 借还款管理

- 支持任意笔数的借款（金额 + 日期）与还款（金额 + 日期）自由录入
- 还款方式可逐笔选择：**先息后本** / **先本后息**
- 先息后本模式下，利息冲减单独一行展示（红色负数），清晰呈现资金流向

### LPR 利率配置

- **内置** 2019-08-20 至今的完整 LPR 历史数据（1年期 + 5年期）
- **自动更新**：每月 20 日新一期发布后，打开页面即自动追加到本地数据，只追加更晚的期数，不改动已有数据
- 支持**倍率模式**（如 × 1.5）或**加点模式**（如 +50BP），可分时段设置不同倍率/加点
- 支持**固定利率**计算（不依赖 LPR）
- LPR 数据支持多种方式导入：
  - JSON 文件
  - 纯文本（`YYYY-MM-DD\t3.00%\t3.50%` 格式，可直接从官网复制粘贴）

### 计算与结果

- 日利率基数可选 **365 天** 或 **360 天**
- 计息截止日期可自由指定
- 修改任一输入即**实时重新计算**，无法计算时直接在结果区说明原因
- 汇总突出「本息合计（未还）」，并列出借还款总额、利息合计、已还/未还利息等
- 结果表格展示：计息区间、类型、发生金额、年利率（含 LPR 与倍率/加点）、计息天数、利息、冲息、还本、剩余本金、备注
- 页面滚动到录入区时，底部常驻显示本息合计，可一键跳到明细
- 一键复制为 **Excel 制表符**格式或 **CSV** 格式，粘贴即用

### 计息口径

- **单利、算头不算尾**：借款当日起计息，计至截止日前一日（截止日当天不计息）；还款日当天起按还款后的本金计息
- **分段计息**：在借还款日、LPR 调整日、倍率/加点生效日处切分，每段按段首生效的年利率计算：`本金 × 年利率 ÷ 日利率基数 × 天数`
- **LPR 浮动**：按每期公布日即时调整。如需按某一时点（如合同成立或起诉时）的 LPR 固定计息，请使用固定利率模式
- **舍入**：每段利息四舍五入到分后再累加，表格逐行利息之和与合计一致
- **同日事件**：先借款后还款，同类型按录入顺序处理
- **溢缴**：还款超过当时应还本息的部分不参与冲抵，单独列为「溢缴金额」并提示
- **数据校验**：计息区间早于首条 LPR 数据（默认 2019-08-20）、日期格式不规范、倍率/加点未填写时直接报错；晚于截止日的借还款不参与计算并给出提示

### 数据持久化与导入导出

- 自动保存所有输入数据到 `localStorage`，刷新页面不丢失
- 支持将当前状态（所有借还款条目、LPR 配置、基础设置）**导出为 JSON**
- 支持从 JSON 文件**一键还原**全部数据

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 运行单元测试
npm test

# 构建生产包
npm run build

# 本地预览构建产物
npm run preview

# 联调 LPR 自动更新：先在另一个终端启动 Worker（本地模拟 KV，监听 8787），
# npm run dev 会把 /api 代理过去
npm run dev:worker
```

本地 Worker 启动后可手动触发定时任务：`curl "http://localhost:8787/__scheduled?cron=0+2+1+*+*"`。

## LPR 自动更新

数据来源为[中国银行 LPR 页面](https://www.boc.cn/fimarkets/lilv/fd32/201310/t20131031_2591219.html)，该页面列出 2019-08-20 以来的全部期数。

- **Worker 定时任务**：每月 20–31 日北京时间 10:00–18:00 每小时检查一次，本期抓到后直到下月 20 日都直接跳过；每月 1 日再做一次核对。请求带 ETag，页面未变化时中行返回 304
- **校验**：首期为 2019-08-20、每月恰好一期且不断档、利率在合理范围、不少于上一版。校验或请求失败时保留 KV 中的原数据并记录错误
- **日期修正**：中行页面把 2021-02-20（春节调休上班日）误写为 2021-02-22，以中国货币网为准修正，修正表见 `src/utils/bocLpr.js`
- **接口**：`GET /api/lpr` 返回全部期数（支持 ETag/304）；`GET /api/lpr/status` 查看最近一次抓取时间与错误
- **前端**：本地最新一期的次月 20 日 10:00 后，打开页面时请求 `/api/lpr` 并追加新期数；没拿到新一期时最多每小时再查一次

## LPR 数据导入格式

**JSON 格式**（数组）：

```json
[
  { "date": "2024-11-20", "lpr1y": 3.1, "lpr5y": 3.6 },
  { "date": "2025-01-20", "lpr1y": 3.1, "lpr5y": 3.6 }
]
```

**纯文本格式**（Tab 或逗号分隔，可直接从央行/Wind 复制）：

```
2025-01-20	3.10%	3.60%
2024-11-20	3.10%	3.60%
2024-10-21	3.10%	3.60%
```

│   ├── SummaryBar.jsx        # 底部本息合计摘要条
│   └── CardHeader.jsx        # 卡片标题栏
├── utils/
│   ├── calculate.js          # 核心计息逻辑
│   ├── date.js               # 日期解析、规范化与本地 today()
│   ├── lprText.js            # 粘贴 LPR 文本解析
